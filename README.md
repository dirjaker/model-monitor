## ✨ 功能特性

- 代理模式

- Web仪表盘
- TUI终端
- macOS菜单栏
- MiMo支持
- 多账户管理

## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/dirjaker/model-monitor.git
cd model-monitor

# 创建虚拟环境
conda create -n model-monitor python=3.12 -y
conda activate model-monitor

# 安装依赖
pip install -r requirements.txt

# 运行项目
python main.py
```
